# Alerts for GitHub — support

Bug reports and feedback for the **Alerts for GitHub** browser extension, a
toolbar popup with your GitHub notifications and pull requests waiting on
your review.

- **Report a problem:** [open an issue](../../issues/new/choose). The
  extension's settings page has a **Report a problem…** button that brings
  you here with a diagnostic report already filled in; it never includes
  your token, and repository names and search queries are replaced with
  placeholders.
- **Privacy policy:** <https://gist.github.com/cvl121/16aff332897a81a4c38da4d6b2799919>

The extension's source is maintained in a private repository; this one holds
the issue tracker only.
